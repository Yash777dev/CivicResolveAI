# CivicResolve AI Data Directory

This directory stores seed data, category taxonomy, and sample records for testing and demonstration.

## Files
- `category_taxonomy.json`: Canonical hierarchy of municipal departments, complaint categories, default SLA hours, and multilingual keywords (English & Tamil).
- `sample_complaints.csv`: Benchmark seed grievances featuring structured factors (immediate danger, essential facility impact, duration) and multilingual text used for testing the deterministic priority engine and optional ML category classifier.
